# 라즈베리파이 부팅 시 자동실행

날짜: 2026년 7월 29일
생성자: LED·RFID 담당

### 동작 흐름

```bash
라즈베리파이 전원 ON
        ↓
라즈베리파이 OS 부팅
        ↓
네트워크 준비 대기
        ↓
systemd가 rfid-mqtt.service 자동 실행
        ↓
가상환경 Python으로 rfid_mqtt.py 실행
        ↓
MQTT 브로커 192.168.0.33:1883 연결
        ↓
RFID 스캔 루프 시작
        ↓
카드 감지 시 DETECTED 이벤트 발행
        ↓
카드 제거 시 REMOVED 이벤트 발행

```

### systemd란

---

리눅스에서 **시스템이 부팅될 때 어떤 프로그램을 자동으로 실행할지 관리해주는 관리자**

systemd는 서비스 단위로 프로그램을 실행하고 관리함.

![image.png](%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC%ED%8C%8C%EC%9D%B4%20%EB%B6%80%ED%8C%85%20%EC%8B%9C%20%EC%9E%90%EB%8F%99%EC%8B%A4%ED%96%89/image.png)

systemd가 라즈베리파이 안에서 하는 일

- 전원 ON → 리눅스 부팅 시작 → 네트워크 켜기 → SSH 서버 켜기 → 블루투스 켜기 …

### 자동 실행 서비스 만들기

---

1. 권한 부여

```bash
chmod +x /home/ssafy/rfid-test/rfid_mqtt.py
```

1. 서비스 파일 생성

```bash
sudo nano /etc/systemd/system/rfid-mqtt.service
```

```python
[Unit]
Description=RFID MQTT Auto Runner
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ssafy
WorkingDirectory=/home/ssafy/rfid-test
ExecStart=/home/ssafy/rfid-test/.venv/bin/python /home/ssafy/rfid-test/rfid_mqtt.py

Restart=always
RestartSec=3

Environment=PYTHONUNBUFFERED=1
Environment=PATH=/home/ssafy/rfid-test/.venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

[Install]
WantedBy=multi-user.target

```

- `/home/ssafy/rfid-test/.venv/bin/python /home/ssafy/rfid-test/rfid_mqtt.py`
: 자동 실행 서비스에서는 `source activate`를 사용하지 않고, 가상환경 내부의 Python 실행 파일을 직접 사용
1. systemd 등록

```bash
sudo systemctl daemon-reload
sudo systemctl enable rfid-mqtt.service
sudo systemctl start rfid-mqtt.service
```

1. 상태 확인

```bash
sudo systemctl status rfid-mqtt.service
journalctl -u rfid-mqtt.service -f
```

![image.png](%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC%ED%8C%8C%EC%9D%B4%20%EB%B6%80%ED%8C%85%20%EC%8B%9C%20%EC%9E%90%EB%8F%99%EC%8B%A4%ED%96%89/image%201.png)

1. 재부팅 테스트

```bash
sudo reboot
systemctl status rfid-mqtt.service
```

### 자주 쓰는 명령어

---

#### [로컬 PC] 터미널

상태 확인

```bash
ssh ssafy@192.168.0.250 'systemctl status rfid-mqtt.service'
```

실시간 로그 확인

```bash
ssh ssafy@192.168.0.250 'journalctl -u rfid-mqtt.service -f'
```

#### [라즈베리파이] 터미널

상태 확인

```bash
systemctl status rfid-mqtt.service
```

실시간 로그 확인

```bash
journalctl -u rfid-mqtt.service -f
```

코드 수정 후 서비스 재시작

```bash
sudo systemctl restart rfid-mqtt.service
```

서비스 중지

```bash
sudo systemctl stop rfid-mqtt.service
```

서비스 시작

```bash
sudo systemctl start rfid-mqtt.service
```

부팅 자동 실행 해제

```bash
sudo systemctl disable rfid-mqtt.service
```

부팅 자동 실행 다시 활성화

```bash
sudo systemctl enable rfid-mqtt.service
```
