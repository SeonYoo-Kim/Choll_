## 작업 범위
사용자의 명시적인 요청이 없는 한 이 디렉토리(`motor/`) 하위만 대상으로 작업합니다.

## PinMap
PinMap은 프로젝트의 고정 사항입니다.
사용자의 명시적인 요청이 없는 한 `.ioc`의 Pin 설정 및 주변장치 설정(GPIO, Timer, PWM, UART, SPI, I2C, ADC, DMA, Interrupt 등)을 수정하지 않습니다.
PinMap 변경이 필요하면 자동으로 수정하지 말고 먼저 사용자에게 제안합니다.

## CubeMX
CubeMX 설정은 `.ioc` 파일을 정본으로 사용합니다.
`.ioc` 파일은 사용자의 명시적인 요청 없이 수정하지 않습니다.
자동 생성 코드는 사용자의 요청 없이 수정하지 않습니다.

## 수정 원칙
요청한 기능과 직접 관련된 파일만 수정합니다.
사용자의 요청이 없는 한 불필요한 리팩토링, 파일 이동, 함수 이름 변경, 코드 스타일 변경은 수행하지 않습니다.

## 작업 원칙
가능한 적은 파일만 읽고 수정합니다.
필요한 파일만 확인하며, 불필요하게 상위 디렉토리나 다른 모듈을 탐색하지 않습니다.
확실하지 않은 내용은 추측하지 않습니다.
PinMap, 통신 인터페이스, 하드웨어 구성, 전기적 연결은 확인이 필요한 경우 사용자에게 먼저 질문합니다.
