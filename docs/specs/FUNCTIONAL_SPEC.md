## FE 기능 명세

### 기능 (우선순위)
- 각 슬롯의 상태(비어 있음/책 있음/인식 실패) — 상
- 슬롯이 실제로 비워졌는지 확인 — 상
- 슬롯별 책 정보: 제목, 구역 번호, id — 상
- 현재 카트가 근접한 서가 구역 및 도착 알림 — 상
- 해당 구역에 꽂아야 할 책이 있는 슬롯 표시 — 상
- 해당 구역에 꽂을 책 카운트 — 상
- 위치 지도 표시 — 상
- 전체 진행률: 카트에 남은 책 수 / 완료된 책 수 — 상
- 사용자 목적지 지정 — 상
- 구역 이동 완료 후 "이 구역 작업 끝" 알림 — 상
- 카트 현재 상태(정지/운행) — 상
- 카트 호출 버튼 — 상
- 이동 취소 (제자리/멈춤) — 상
- 추종 시작 종료 기능 — 상
- 필터링 — 상
- 사서 로그인 (사서별 id로 분리되도록) — 하
- RFID 재인식 요청 알림 — 하
- 도서 검색 기능(책장별로) — 하

### 비기능 (우선순위)
- 서버/DB 연결 상태 — 상
- 동기화 지연 여부 — 상
- 에러 로그/알림 — 중
- 배터리 잔량 — 하

## AI 기능 명세

- 사서를 인식하고 따라갈 방향 제시
  - 카메라로 사람 인식
  - 따라갈 사람(사서) 선택
  - 사서의 특징 추출하여 tracking
  - 화면에서 사라져도, occlusion 발생해도 tracking 유지

```
Initial Registration → Memory Bank Creation → Normal Tracking → Target Lost → Re-ID Matching → Recover Target
```

- 사서가 중앙에 위치할 수 있도록 북카트가 이동할 방향 계산

파이프라인:
```
RGB Camera
→ YOLOv10s TensorRT (Person Detection)
→ ByteTrack (Assign Track IDs)
→ Operator selects librarian (manual)
→ OSNet Feature Extraction (512-D)
→ Memory Bank Initialization
→ (Tracking Success | Target Lost → Re-ID Matching)
→ Update Target Track ID
→ Image Center Error Calculation
→ LiDAR Distance Measurement
→ PID Controller (Keep 1.0 m)
→ Publish /cmd_vel
→ Motor Controller
```

### 1차 개발 우선순위
1. REST API로 카트·슬롯·지도·작업 데이터를 조회한다.
2. 가짜 카트가 MQTT로 위치와 슬롯 상태를 전송한다.
3. Backend가 MQTT 데이터를 처리하고 DB를 갱신한다.
4. Backend가 WebSocket으로 변경 내용을 FE에 전달한다.
5. FE의 이동 요청을 Backend가 MQTT 명령으로 변환한다.
6. 현재 구역을 판정하고 해당 구역의 슬롯 LED 명령을 전달한다.
7. 이후 추종과 WebRTC 영상 연결을 추가한다.
