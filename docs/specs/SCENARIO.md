# 시연 시나리오

> 실제 발표 시연(2026-08-11)의 진행 대본 (2026-08-10 작성). 팀원은 역할로 표기.
> 시연 당일 시스템 구성(시나리오 A/B/C 분기)은 [DEMO_RUNBOOK.md](../DEMO_RUNBOOK.md) 참조.

## 사용자 흐름 (유저 플로우 요약)

1. **적재**: 사서가 반납 도서를 카트 슬롯에 꽂음 → RFID 인식 → 웹 화면에 슬롯별 도서 정보·목표 구역 표시
2. **추종 시작**: 웹에서 추종 시작 → 카메라 영상에서 추종 대상(사서) 선택 → 카트가 사서를 따라 이동
3. **구역 진입**: 카트가 책장 구역에 진입 → 도착 팝업 + 해당 구역에 꽂을 책이 있는 슬롯 LED 점등
4. **정리**: 사서가 LED 켜진 슬롯의 책을 꺼내 서가에 배치 → 슬롯 상태 갱신, 정리 진행률 상승
5. **반복**: 다음 구역으로 이동하며 2~4 반복 → 전체 정리 완료

## 시연 대본 (2026-08-10)

1. 뒤쪽 노트북 테이블 앞에서 뒷문 쪽을 보고 구동 시작
2. EM 담당자가 책을 꽂고, 다른 EM 담당자가 LED·카메라 촬영 → 3권째 꽂으면 줌아웃 풀샷
3. FE 담당자와 EM 담당자가 카메라에 잡히고, FE 담당자를 추종 대상으로 선택
4. 카트를 데리고 Z2로 이동 → (위치는 수동 발행) 좌표 발행으로 LED 점등 확인
5. 책이 빠지면 슬롯 상태가 빠지는 것 보여주기
6. 책 정리 후 그대로 직진해서 Z3로 이동 → 여기서도 책 정리
7. 책이 빠지면 정리율 오르는 것 보여주기
